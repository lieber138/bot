# AstrBot 知识库资料

本仓库当前提供一份可上传到 AstrBot 知识库的 Markdown 文档：

- `knowledge_base/yoisaki_kanade_astrbot.md`：宵崎奏剧情蒸馏知识库，包含角色设定、剧情主线、人物关系、重点活动、主题词典、常见问答和检索标签。

## 导入方式

1. 在 AstrBot WebUI 中创建或打开一个知识库。
2. 上传 `knowledge_base/yoisaki_kanade_astrbot.md`。
3. 等待 AstrBot 完成解析、切分与向量化。
4. 在会话配置中启用该知识库，或在聊天时指定使用该知识库。

AstrBot 官方文档说明，创建知识库后可以上传文档；新版知识库支持同时上传最多 10 个文件，单个文件大小不超过 128 MB。

## 建议配置

- 知识库名称：`pjsk_yoisaki_kanade_story`
- 内容语言：中文
- 推荐用途：Project SEKAI 剧情问答、宵崎奏人物分析、N25 关系检索、二创资料整理。
- 推荐检索词：`宵崎奏`、`奏`、`Kanade`、`K`、`25时`、`Nightcord`、`真冬`、`救赎`、`作曲`。

## 内容边界

该知识库是剧情蒸馏与分析资料，不包含官方剧情全文、卡面剧情逐字稿或歌词全文。
